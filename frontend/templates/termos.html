Termos de Uso

DynaPrice — Projeto universitário

Importante: O DynaPrice é um projeto desenvolvido no âmbito universitário, com finalidade exclusivamente acadêmica e sem fins lucrativos.

1. Sobre o projeto

O DynaPrice é um projeto universitário criado com o objetivo de aplicar e demonstrar conhecimentos de desenvolvimento de software, gerenciamento de produtos, controle de estoque, registro de vendas e gerenciamento de preços e etiquetas.

2. Ausência de fins lucrativos

O projeto não possui fins lucrativos. Seu desenvolvimento tem como propósito o aprendizado, a experimentação e a demonstração de conhecimentos adquiridos no ambiente acadêmico, não tendo como objetivo principal a obtenção de lucro comercial.

3. Finalidade de uso

O sistema foi desenvolvido para fins educacionais e de demonstração. Suas funcionalidades podem ser modificadas, apresentar limitações ou passar por atualizações durante o desenvolvimento acadêmico.

4. Responsabilidade pelas informações

Os usuários devem conferir os dados cadastrados, incluindo produtos, preços, quantidades em estoque e registros de vendas. Por se tratar de um projeto acadêmico, o sistema não deve ser considerado, sem as devidas validações, uma solução comercial pronta para uso profissional.

5. Dados e privacidade

As informações inseridas no sistema devem ser utilizadas de maneira responsável e compatível com a finalidade do projeto. Caso sejam tratados dados pessoais, seu responsável deverá observar as normas de privacidade e proteção de dados aplicáveis.

6. Limitações do sistema

O DynaPrice pode apresentar falhas, indisponibilidade ou funcionalidades incompletas durante seu desenvolvimento. Recomenda-se manter cópias de segurança dos dados importantes e não depender exclusivamente do sistema para operações críticas.

7. Atualizações dos termos

Estes termos poderão ser atualizados conforme a evolução do projeto e a implementação de novas funcionalidades.

8. Contato

Para dúvidas ou esclarecimentos sobre o projeto, entre em contato com a equipe responsável pelo desenvolvimento acadêmico do DynaPrice.

Este documento apresenta as condições gerais de uso do projeto acadêmico DynaPrice.
